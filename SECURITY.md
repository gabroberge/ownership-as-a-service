# Security Policy

## Supported versions

Ownership-as-a-Service is currently under active development. Only the latest version is supported.

## Reporting a vulnerability

If you discover a security vulnerability, please report it privately using GitHub's security advisory feature rather than opening a public issue.

Please include enough information to reproduce and understand the issue.

## Scope

Ownership-as-a-Service is a static satirical marketing site. It has no backend, authentication system, database, or user data. Nothing is stored, collected, or processed. The platform does not actually observe your organization, although your organization may already behave as if it does.

Security issues affecting visitors, such as cross-site scripting, injection vulnerabilities, exposed secrets, or vulnerable dependencies, are in scope.

Fictional product behavior, fabricated metrics, the absence of the advertised inference engine, and responsibility for this repository converging on a single maintainer are not security vulnerabilities. The last one is expected model behavior.

## Response

Valid reports will be reviewed as time permits. Reports are reviewed by whoever notices them, which historically has been the same person. There is no bug bounty program.

## Safe harbor

Good-faith security research is welcome. Please avoid disruptive testing against the production deployment.
